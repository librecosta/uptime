v0.2.0 adds optional DOWN/RECOVERED alerts to LibreCosta Uptime.

- **Notifications:** Generic Webhook and Feishu/Lark, with per-endpoint channel selection.
- **Failure detection:** DOWN after 1–10 consecutive failures (default 3); RECOVERED on the first successful check.
- **Persistent delivery:** Incidents and pending notifications survive restarts with bbolt or Redis, with bounded retries.

Alerts are **disabled by default**. See the [configuration example](https://github.com/librecosta/uptime/blob/v0.2.0/configs/uptime.example.yaml).

**Upgrade note:** Existing monitoring data is unchanged. With bbolt alerts, back up both `uptime.db` and `alerts.db`. Delivery can repeat; use one alert executor per database or Redis prefix.
