# LibreCosta Uptime v0.1.1

Security maintenance release for the v0.1 series.

## Security and build updates

- Rebuild the five platform distribution archives with the patched Go 1.26.10 toolchain.
- Pin the Docker build stage to `golang:1.26.10-bookworm` while retaining the existing non-root Distroless runtime.
- Require patched Go releases in CI (Go 1.26.10+ and 1.27.3+) and have the distribution and release workflows select the module's recommended toolchain.

The minimum supported Go language/module version remains 1.26.0. No third-party dependencies are upgraded in this release.

## Compatibility

This release changes no Uptime features, CLI commands, HTTP endpoints, YAML configuration, persistent database format or Redis key layout. Existing v0.1.0 deployments do not require a data migration.

## Upgrade

Download the v0.1.1 archive for your OS/architecture from [GitHub Releases](https://github.com/librecosta/uptime/releases/tag/v0.1.1), verify it using the accompanying `SHA256SUMS`, and replace the executable while the service is stopped. Keep the existing YAML configuration and persistent data.

For Docker deployments, upgrade to `ghcr.io/librecosta/uptime:v0.1.1`. Preserve the existing configuration mount and persistent data volume; follow the [Docker deployment guide](https://github.com/librecosta/uptime/blob/v0.1.1/docs/deployment/docker.md).

As with v0.1.0, stop the service before bbolt file backup or offline service management. See the [README](https://github.com/librecosta/uptime/blob/v0.1.1/README.md) for platform archives, setup and operational limits.
