v0.2.1 adds private operational dashboards and more control over alert recovery.

- Browse incidents and per-channel delivery outcomes in the optional authenticated `/alerts` dashboard.
- View process and HTTP metrics in the optional authenticated `/monitor` dashboard. The Uptime dashboard and status API can be made public separately.
- Set how many consecutive successes resolve an alert and enable reminders for ongoing failures.

**Before upgrading**, stop all alert executors and back up monitoring and alert state together. Enabled bbolt and Redis alert storage migrate at startup. Roll back only by restoring the complete pre-upgrade backup with the previous version.
